# Safi Ahmad - Week 1 Full-Stack Project

## Project Description

A full-stack user registration system built using React, Node.js, Express, MongoDB Atlas, and bcrypt. The project includes frontend form validation, a RESTful registration API, secure password hashing, and database integration.

## Technologies Used

### Frontend
- React
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js
- Mongoose
- bcrypt
- CORS
- dotenv

### Database
- MongoDB Atlas

### API Testing
- Postman
